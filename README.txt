PRANAV & ASMITA — WEDDING WEBSITE

1. Open index.html to preview locally.
2. Upload your wedding invitation video to:
   assets/wedding-invite.mp4
   The video button will then play it on the front page.
3. The countdown is set to 24 November 2026 at 9:00 AM IST.
4. Google Maps venue button is already linked.
5. RSVP phone and WhatsApp links are already added.
6. To edit text, open index.html.
7. To change colors/fonts/layout, edit css/styles.css.
8. To change countdown target, edit the target date in js/script.js.

For GitHub Pages: upload the contents of this folder to your repository and enable Pages from Settings > Pages, using the main branch/root.
